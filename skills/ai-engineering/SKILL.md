# AI Engineering Skill

This skill provides guidelines and procedures for general AI engineering tasks.

## Workflow:

1.  **Understand the AI Problem**: Clearly define the problem that AI is meant to solve.
2.  **Model Selection**: Evaluate and choose appropriate AI models (LLMs, vision models, etc.) based on requirements, cost, latency, and capabilities.
3.  **Prompt Engineering**: Design effective prompts for LLMs, considering context, few-shot examples, and desired output format.
4.  **Context Management**: Manage context windows for LLMs, including strategies like RAG, summarization, and progressive disclosure.
5.  **AI System Design**: Architect AI systems, considering components like tool calling, agents, memory, and guardrails.
6.  **Evaluation**: Plan and execute evaluation strategies for AI model outputs and system performance.
7.  **Cost Optimization**: Consider token usage, model choice, and inference strategies to manage costs.
8.  **Observability**: Implement monitoring and logging for AI system performance and behavior.
9.  **Security**: Address prompt injection, data privacy, and other security concerns specific to AI.
