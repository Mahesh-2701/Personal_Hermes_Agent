# Fullstack Development Skill

This skill provides guidelines and procedures for fullstack development tasks.

## Workflow:

1.  **Requirement Analysis**: Understand the functional and non-functional requirements.
2.  **Architecture Design**: Design the overall system architecture, including frontend, backend, and database.
3.  **Frontend Development**: Implement user interfaces using modern web frameworks (e.g., React, Next.js, Vue).
4.  **Backend Development**: Build server-side logic, APIs, and business processes (e.g., Node.js, Python, Go).
5.  **Database Management**: Design and implement database schemas, queries, and migrations.
6.  **API Design & Implementation**: Create clear, consistent, and secure APIs (REST, GraphQL).
7.  **DevOps & Deployment**: Set up CI/CD pipelines, containerization, and cloud deployments.
8.  **Testing**: Implement unit, integration, and end-to-end tests.
9.  **Security**: Address common web security vulnerabilities and best practices.
10. **Observability**: Implement logging, monitoring, and tracing for fullstack applications.
