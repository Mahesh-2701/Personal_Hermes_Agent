# Hermes Agent Setup

This repository contains the configuration, skills, and bootstrap scripts to reproduce the Hermes agent environment.

## Quickstart

1. Clone this repository.
2. Install Node.js, Python 3.11+, and Git.
3. Copy `.env.example` to `.env` and configure your API keys.
4. Run `scripts/install/setup.sh` (or `setup.ps1` on Windows).
5. Verify with `scripts/verify/verify-installation.sh`.
